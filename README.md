# planets-database

## Description
This repository is a practice project for learning Git and GitHub workflows using GitHub Desktop and VS Code. It demonstrates how to create a repository, organize files locally, and track changes using version control.

The project focuses on basic planetary data from our solar system and is structured to practice working with folders, text files, and CSV data.

## Repository Structure
The repository is organized as follows:

planets-database/  
├── inner-planets/  
│   ├── mercury.txt  
│   └── venus.txt  
├── outer-planets/  
└── data/  
    └── planet-stats.csv  

### Folder Details
- **inner-planets/**  
  Contains text files with factual information about inner planets such as Mercury and Venus.
- **outer-planets/**  
  Reserved for future files related to outer planets.
- **data/**  
  Contains a CSV file with structured planet statistics including distance from the Sun, diameter, and number of moons.

## Included Files
- `inner-planets/mercury.txt` — 3–5 facts about Mercury  
- `inner-planets/venus.txt` — 3–5 facts about Venus  
- `data/planet-stats.csv` — Planet data in CSV format

## Fun Fact 🪐
A day on Venus is longer than a year on Venus — it rotates so slowly that it takes longer to spin once than to orbit the Sun.
