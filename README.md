# planets-database

## Description
This repository is a practice project for learning Git and GitHub workflows using GitHub Desktop and VS Code. It demonstrates how to create a repository, organize files locally, and track changes using version control.

The project focuses on basic planetary data from our solar system and is structured to practice working with folders, text files, and CSV data.

## Fun Fact 🪐
A day on Venus is longer than a year on Venus — it rotates so slowly that it takes longer to spin once than to orbit the Sun.

## Planet Overview

**Mercury** is the smallest planet in the solar system and the closest to the Sun. Because it has almost no atmosphere, Mercury experiences extreme temperature changes—very hot during the day and extremely cold at night. Its surface is heavily cratered, similar to Earth’s Moon, showing that it has remained largely unchanged for billions of years.

**Venus** is often called Earth’s “sister planet” due to its similar size, but its environment is far more extreme. A thick atmosphere made mostly of carbon dioxide traps heat, making Venus the hottest planet in the solar system. Venus also rotates very slowly and in the opposite direction of most planets.

**Jupiter** is the largest planet in the solar system and is famous for its massive storms. The Great Red Spot is a giant storm that has been active for hundreds of years. Jupiter is a gas giant, meaning it does not have a solid surface, and it has many moons orbiting it.

**Saturn** is best known for its impressive ring system, made of ice, rock, and dust. Like Jupiter, Saturn is a gas giant and has numerous moons, including Titan, which is larger than Mercury. Saturn is also the least dense planet in the solar system.
